# Генератор экзаменационных билетов

Первая версия приложения для формирования билетов из Excel-реестра вопросов.

## Возможности

- чтение реестра без изменения исходного файла;
- выбор всех или отдельных категорий;
- проверка ошибок перед генерацией;
- формирование отдельных файлов `Билеты N категория DD месяц YYYY.xlsx`;
- формирование файла `Статистика генерации DD месяц YYYY.xlsx`;
- 4 основных билета отмечаются звездочкой на листе `Идентификаторы`;
- параметры по умолчанию: 10 билетов, 50 тестовых, 3 тематических, 2 практические.
- каждый запуск использует новый seed, поэтому при тех же исходных данных билеты
  будут отличаться;
- в одном билете по умолчанию используется не больше 4 тестовых вопросов из одной темы.

## Запуск из исходников

```bat
pip install -r requirements.txt
python main.py
```

## Сборка EXE

На Windows выполнить:

```bat
build_exe.bat
```

Для Windows 7 рекомендуется собирать приложение на машине с Windows и Python 3.8.x.
Результат будет в папке `dist\TicketGenerator`.
Внутри сборки служебные библиотеки и DLL находятся в подпапке `_internal`.
Архив `base_library.zip` является штатной частью PyInstaller-сборки, удалять его нельзя.

## Сборка через GitHub

В репозитории есть workflow `.github/workflows/build-windows.yml`.
Он собирает приложение на Python 3.8 в формате папки `dist/TicketGenerator`
и прикладывает ее как artifact `TicketGenerator-windows`.

## Важное ограничение

Если в реестре есть критические ошибки, генерация блокируется. Например, ID вопроса
должен начинаться с номера категории. Для текущего реестра известный пример:
в категории 4 идентификатор `5163` должен быть исправлен на `4163`.
